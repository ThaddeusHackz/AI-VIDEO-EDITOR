## 6. Add your own render here

```bash
# Remotion
cd remotion && npx remotion render src/index.ts Cinematic3D-Showcase out/my-film.mp4

# HyperFrames
cd examples/ultrahigh-3d-vfx-showreel && hyperframes render -o renders/showreel.mp4 -f 30 -q standard

# Upload the finished file to the Drive folder, then add a row to this table
# and to the showcase table in README.md so viewers can watch it.
```

**Naming convention used by this gallery** (keeps the folder sortable and self-describing):

```text
<CHANNEL-OR-SERIES>-<Title>-<WxH or tag>-<duration>s-<quality-tag>.mp4
e.g. THADDEUS-TECHZ-Jason-Statham-Dark-Pursuit-4K-90s-ULTRA-BITRATE-3D.mp4
```
