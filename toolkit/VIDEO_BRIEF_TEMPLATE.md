## 7. Review gates

- [ ] Verify source files exist; inspect metadata and listen to supplied audio.
- [ ] Verify exact copy, factual claims, names, prices, and CTA.
- [ ] Beat durations sum to target runtime; no accidental empty tail.
- [ ] Review representative stills before full-quality render.
- [ ] Run the relevant lint/check/type checks.
- [ ] Inspect transitions, captions, contrast, safe areas, and portrait/mobile readability.
- [ ] Watch the complete draft with sound.
- [ ] Fix one concrete issue at a time; preserve what already works.
- [ ] Probe final metadata and full-decode the exported MP4.
- [ ] Confirm final package contains only requested deliverables.
